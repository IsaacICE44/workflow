# Roteiro para jogos

Identifique a engine, a plataforma e o comportamento que o jogador deve observar. Valide controles, transições de estado, saves e compatibilidade com clientes existentes conforme o escopo. Rode o jogo no alvo disponível. Em Android, siga as regras do projeto para exploração com ARTEMIS antes de escrever testes. No navegador e no desktop, confirme a interação real e os estados adjacentes.

O [catálogo de capacidades](capacidades.md) lista integrações opcionais para arte, HUD, playtest e entrega.
